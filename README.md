# Nova Care Cloud — GRC Compliance Automation & Executive Dashboard

**Project type:** Simulated GRC portfolio exercise. Nova Care Cloud, vendors, audit data, and findings are fictional.

## Scenario
As a simulated GRC Analyst, consolidate SOC 2, HITRUST-aligned and HIPAA-aligned control status, audit evidence, third-party risk, and remediation items into a single leadership view. This is an educational simulation and does not constitute a formal SOC 2 audit, HITRUST assessment, or HIPAA compliance determination.

## Deliverables
- `Nova_Care_Cloud_GRC_Compliance_Dashboard.xlsx`: live Excel dashboard with six worksheets and status validation.
- `CISO_EXECUTIVE_BRIEF.md`: risks and recommended decisions.
- `ANALYST_EXERCISES.md`: guided practice and acceptance checks.

## Workbook tabs
1. **Executive Dashboard:** formula-driven summary for the CISO.
2. **Control Register:** example controls with status and owners.
3. **Evidence Tracker:** requests, receipt status, and reviewer notes.
4. **Vendor Risk:** fictional vendors, BAA status, onboarding decisions.
5. **Findings & Actions:** severity, owners, deadlines, and remediation.
6. **Instructions:** edit and verify the tracker.

## Skills demonstrated
Security governance, control monitoring, evidence management, third-party risk, HIPAA BAA awareness, exception management, remediation tracking, Excel dashboard reporting.

## Safety and accuracy
No real patient data or company evidence is included. HITRUST control examples are independently authored and not presented as exact licensed framework requirements. Statuses are fictional demonstration records, not proof of real-world control operation.
